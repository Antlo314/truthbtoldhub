# Third-party assets

## 3D models — `public/models/kenney/`

**Kenney Furniture Kit** and **Kenney Nature Kit** — https://kenney.nl
Licence: **Creative Commons Zero (CC0 1.0)** — public domain. Attribution is
not required and redistribution is permitted; the packs' own `License.txt`
files ship alongside the models in this folder.

Kenney asks (optionally) to be credited, so: **models by Kenney (kenney.nl)**.
Their one restriction is not using the Kenney logo, which we don't.

Only the models actually used in the house are committed here, converted to
nothing — these are the kits' own `.glb` exports, unmodified.

## Models authored for this project — `public/models/vessels/`

`vessel_man.glb`, `vessel_woman.glb` — Blender blockouts made for Truth B Told
Hub. Original work, no third-party licence.

## Icons

Truth.OS app glyphs (`components/truthos/OsGlyph.tsx`) are original artwork
drawn for this project. No third-party icon pack is used for them, so there
are no attribution obligations.
